## Eval (Industry Thinking — judgments formed through practice)
1. **Token Economics — not all tokens are worth the same**: value comes from how deeply a token is
   embedded in the value chain. Four levels: trigger conversation → recommendation → decision → transaction.
   The model determines cost; the product determines value.
2. **Seat-based → Outcome-based business models**: when AI independently delivers legal consulting,
   analysis, or video, the SaaS "sell seats" model breaks. Harvey sells legal consulting; Keling/Jimeng
   sell content. Payment shifts from tools to outcomes.
3. **Application-layer moats** (model providers entering the app layer directly): weak→strong —
   (1) distribution & customer relationships, (2) closed-loop data, (3) industry liability (legal entity + SLA),
   (4) vertical regulatory barriers, (5) physical world (embodied intelligence). None are technology itself —
   they're trust, relationships, liability, regulation, physical assets.
4. **Agent = Model + Harness**: Harness engineering (memory, tool use, MCP, multi-agent) is how model
   capability reaches the app layer. Principles: reduce pause points (risk-tiered autonomy, persist
   preferences, draft-first reverse inquiry); context isolation (sandbox tasks, natural boundaries like
   Discord channels, file system as shared memory); errors don't accumulate (roll back decisively —
   LLMs regenerate better than patch; multi-agent layering separates execution from value judgment).
5. **Experience · PMF — manufacturing Aha Moments**: AI lowers the cost of building apps and raises
   the baseline expectation for experience. Efficiency gains get copied, so retention needs personalized,
   memorable moments. Patterns: intuitive interaction (typewriter keystroke sound while a voice assistant
   searches), easy entry into existing environments (a coding demo that self-hosts LAN projection),
   slightly beyond expected understanding (generation quality that makes users feel understood).
