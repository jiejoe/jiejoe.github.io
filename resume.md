## Industry Thinking

Judgments formed through practice in e-commerce and AI application layer. Updated as practice evolves.

### 1. Token Economics — Not all tokens are worth the same

The depth of Token embedding in the value chain determines its value. Triggering a conversation vs. triggering a transaction costs roughly the same in tokens, but the value differs by orders of magnitude.

Four levels: trigger conversation → trigger recommendation → trigger decision → trigger transaction. The model determines cost; the product determines value.

### 2. Seat-based → Outcome-based Business Models

AI transforms knowledge work at exponential scale. When AI can independently deliver legal consulting, analysis reports, or video content, the SaaS model of selling tool seats breaks down. Harvey sells legal consulting, not seats. Keling/Jimeng sell content directly. Payment target shifts from tools to outcomes.

### 3. Application Layer Moats

Model providers are entering the application layer directly (Cowork wiped ~$2T SaaS market cap in one week). Five moats that can withstand this, weak to strong:

1. Distribution & customer relationships (ByteDance, WeChat, DingTalk)
2. Closed-loop data (Harvey, Abridge, Sierra)
3. Industry liability (Sierra, Stripe, Replit) — legal entity + SLA required
4. Vertical regulatory barriers (healthcare, finance, legal)
5. Physical world (1X, Unitree, embodied intelligence)

Common thread: none are technology itself — they're trust, relationships, liability, regulation, and physical assets.

### 4. Agent = Model + Harness

Harness engineering (memory, tool use, MCP, multi-agent) is how model capability enters the application layer. Three design principles from practice:

- **Reduce pause points**: Risk-tiered autonomy. Persist user preferences. Reverse inquiry — draft first, let users critique.
- **Context isolation**: Sandbox each task independently. Use natural product interaction structures such as Discord channels as boundaries. File system as shared memory — more transparent than vector DB.
- **Errors don't accumulate**: Roll back decisively — LLMs regenerate better than patch. Multi-agent layering: separate execution from value judgment, catch errors between layers.

Direction: reduce human intervention frequency while preserving human judgment on critical decisions.

### 5. Experience · PMF — Manufacturing Aha Moments

AI lowers the technical cost of building applications, which also raises users' baseline expectations for traditional software experiences. Efficiency gains will become easier to copy, so AI applications will find it harder to retain users by being merely "faster at solving the problem." Beyond improving solution efficiency in general-purpose workflows, product design needs to create personalized moments that users remember.

Three patterns from practice:

- **Intuitive interaction**: e.g. typewriter-like keystroke sound while a GPT voice assistant is waiting and searching.
- **Easy entry into existing environments**: e.g. a coding demo tool that can self-host a LAN projection mode for local presentation.
- **Slightly beyond expected user understanding**: e.g. visual quality in image, video, and webpage generation that makes the user feel understood.
